| Field      | Value                                                                        |
| ---------- | ---------------------------------------------------------------------------- |

---

## 1. Objective

V8.1 adds a lightweight Pair Profile Engine for attribution research. It does **not** change trading decisions. It exists to:

1. Label every signal with its pair profile.
2. Accumulate attribution data.
3. Validate pair-behaviour hypotheses.
4. Lay the foundation for V8.2 Regime Engine, V8.3 Structure Score and V8.4 Attribution Engine.

## 2. Non-Goals

V8.1 MUST NOT change: signal generation, LGB model prediction, Risk Gate, Core Group Gate, Correlation Gate, position sizing, SL calculation, TP calculation, execution logic, order routing.

## 3. Design Principles

- **Observe only.** V8.1 may write data. It may not affect trades.
- **Fail safe.** Observer failures never interrupt trading. If `pair_profiles.yaml` is deleted, malformed, or holds unexpected values: trading continues, the observer logs the failure (`log.exception` for caught errors, `log.warning` for missing file or bad root), and the fallback profile is used.
- **Switch-gated.** Everything runs behind `V8_PAIR_PROFILE=1`. Default `0`, so V7 behaviour is unchanged.
- **Backward compatible.** Existing lifecycle processors keep working. New fields are optional.

## 4. Profile Hypothesis

Profile labels are research hypotheses, not facts. `EUR_USD: style: mean_reversion` means "we hypothesize EUR_USD behaves closer to a mean-reversion instrument". V8.1 collects evidence; later versions validate or reject it.

## 7. Reference Implementation: `config/pair_profiles.py`

```python
from __future__ import annotations

import copy
import logging
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Final

import yaml

log = logging.getLogger(__name__)

_CONFIG_PATH: Final[Path] = Path(__file__).parent / 'pair_profiles.yaml'
_UNKNOWN: Final[str] = 'unknown'
_FALLBACK: Final[dict[str, dict[str, Any]]] = {'default': {'style': _UNKNOWN}}

_PROFILE_CACHE: dict[str, dict[str, Any]] | None = None


@dataclass(frozen=True, slots=True)
class PairProfile:
    style: str = _UNKNOWN
    category: str = _UNKNOWN
    volatility_rank: str = _UNKNOWN
    expected_regime: tuple[str, ...] = field(default_factory=tuple)

    @classmethod
    def from_mapping(cls, raw: object) -> PairProfile:
        if not isinstance(raw, dict):
            return cls()
        regimes = raw.get('expected_regime') or []
        if not isinstance(regimes, (list, tuple)):
            regimes = [regimes]
        return cls(
            style=str(raw.get('style', _UNKNOWN)),
            category=str(raw.get('category', _UNKNOWN)),
            volatility_rank=str(raw.get('volatility_rank', _UNKNOWN)),
            expected_regime=tuple(str(r) for r in regimes),
        )


def normalize_instrument(instrument: object) -> str:
    # Normalize to OANDA style (EUR_USD). Never raises.
    if not isinstance(instrument, str):
        return ''
    value = instrument.strip().upper().replace('/', '_').replace('-', '_')
    if '_' not in value and len(value) == 6:
        return f'{value[:3]}_{value[3:]}'
    return value


def _read_yaml() -> dict[str, dict[str, Any]]:
    if not _CONFIG_PATH.exists():
        log.warning('pair_profiles.yaml not found: %s', _CONFIG_PATH)
        return copy.deepcopy(_FALLBACK)
    try:
        with _CONFIG_PATH.open('r', encoding='utf-8') as handle:
            data = yaml.safe_load(handle)
    except (yaml.YAMLError, OSError):
        log.exception('Cannot load %s', _CONFIG_PATH)
        return copy.deepcopy(_FALLBACK)
    if not isinstance(data, dict):
        log.warning('pair_profiles.yaml root is not a mapping; using fallback')
        return copy.deepcopy(_FALLBACK)
    return data


def load_pair_profiles() -> dict[str, dict[str, Any]]:
    # Cached raw mapping; returns a copy so callers cannot corrupt the cache.
    global _PROFILE_CACHE
    if _PROFILE_CACHE is None:
        _PROFILE_CACHE = _read_yaml()
    return copy.deepcopy(_PROFILE_CACHE)


def reload_pair_profiles() -> None:
    # Drop the cache; next load re-reads the file (hot-reload / tests).
    global _PROFILE_CACHE
    _PROFILE_CACHE = None


def get_pair_profile(instrument: object) -> PairProfile:
    profiles = load_pair_profiles()
    raw = profiles.get(normalize_instrument(instrument), profiles.get('default'))
    return PairProfile.from_mapping(raw)


def get_pair_style(instrument: object) -> str:
    return get_pair_profile(instrument).style
```

Notes:

- A missing or invalid YAML caches the fallback for the process lifetime. Call `reload_pair_profiles()` after fixing the file.
- `load_pair_profiles()` deep-copies per call. If profiling shows cost, switch to `MappingProxyType`.

## 8. Lifecycle Extension

Add to the lifecycle record (`reports/lifecycle.jsonl`):

```json
{"pair_profile": {"style": "mean_reversion", "category": "major"}}
```

**Why nested:** V8.2+ can add `volatility_rank`, `expected_regime` and so on with no schema migration.

**Absence semantics:** a record without the key means the observer did not run (flag OFF, or the early feature-mismatch `_write_lc` path, which intentionally carries no `pair_profile`). Reports must show these as `(absent)`, never as `unknown`.

## 9. Observer Integration

Inside `analyze_cycle()`, immediately before `_write_lc(prob, signal_dir, extra=extra)`. Anchor on function names, not line numbers. `extra` comes from `structure_to_extra(analysis)` and may be `None`.

```python
# module level
_V8_PAIR_PROFILE: Final[bool] = os.getenv('V8_PAIR_PROFILE', '0') == '1'

# in analyze_cycle()
if _V8_PAIR_PROFILE:
    try:
        prof = get_pair_profile(inst)
        new_extra = dict(extra or {})
        new_extra.setdefault(
            'pair_profile',
            {'style': prof.style, 'category': prof.category},
        )
        extra = new_extra  # assign only after success
    except Exception:
        log.exception('pair_profile observer failed: %s', inst)
```

Rules:

- `extra` is reassigned only on success, so a failure cannot leave it half-modified.
- `setdefault` protects keys written by earlier observers. It does not stop a later observer using plain assignment from overwriting this one, so **every V8 observer MUST use `setdefault`** (see Section 10).

## 10. Exception Policy

**Forbidden:** bare `except:`.

**Preferred:** specific exceptions (`yaml.YAMLError`, `OSError`).

**Observer-boundary exception:** the only permitted broad catch is `except Exception:`, and only when all of these hold: observe-only module, logged with `log.exception`, fail-safe, no trading decision involved. Examples: Pair Profile, Regime and Structure observers.

**Observer write rule:** all observers write lifecycle keys with `setdefault` and never overwrite another observer's keys.

## 11. Instrument Normalization

| Input                                                                      | Output                   |
| -------------------------------------------------------------------------- | ------------------------ |
| `EURUSD`, `eurusd`, `EUR/USD`, `eur-usd`, `EUR_USD`, `AUD_NZD` | `EUR_USD`, `AUD_NZD` |

## 12. Testing Requirements

### 12.1 Unit tests (mandatory)

Known pair, unknown pair, missing YAML, invalid YAML, root is a list, entry not a mapping, `expected_regime` scalar, reload picks up changes, cache immutability, normalization (all forms in Section 11), `None` input.

@pytest.fixture(autouse=True)

## 15. Measurement Plan

V8.1 does not attempt improvement. It only collects labels. Regime is not available until V8.2, so the hypotheses below are **evaluated after V8.2**, which recomputes regime offline from stored price history using signal timestamps. This keeps V8.1 scope unchanged. (Open decision D1 covers the alternative of logging raw regime inputs now.)

### 15.1 Baseline first

Before enabling V8.1, compute from V7 attribution data, per pair: MFE and MAE distributions in ATR units, whipsaw rate, and entry offset from the last swing. This turns the assumed V7 weaknesses into measured numbers.

### 15.2 Definitions (initial values; tune on baseline)

- **Whipsaw:** stopped out within N=12 bars of entry, then price moves beyond the entry level in the original direction within M=24 bars after the stop.
- **MFE captured:** realized PnL divided by MFE, per trade, in ATR units.
- **Drawdown:** max drawdown on the same equity basis for all arms.

### 15.3 Hypotheses (pre-registered, one metric each)

- **H1:** Momentum pairs in TREND regimes have a higher median MFE/ATR than mean-reversion pairs.
- **H2:** Mean-reversion and channel styles in RANGE regimes have a lower whipsaw rate than momentum styles.
- **H3 (label validity):** Style generalizes beyond pair identity. Predicting a held-out pair's MFE/ATR from the other pairs sharing its style beats a pooled all-pairs baseline. (Style is a function of pair, so it cannot "explain more variance than Pair ID"; the test is whether it transfers across pairs.) **If H3 fails, labels are noise and must not be used in trading logic.**

### 15.4 Statistics

- Report bootstrap 95% CIs, not only point estimates.
- A bucket counts as improved only if the CI excludes zero difference.
- Apply a multiple-comparison correction across buckets; no post-hoc bucket picking.
- Compare against a concurrent shadow baseline (V7 behaviour), never before/after, because regimes shift.

## 16. Sample Size Rule

Replaces "observe 2 weeks":

- **Per pair:** collect until N >= 30 signals, or stop at 8 weeks and mark the pair "insufficient".
- **Per pair x regime bucket:** same N >= 30 rule, applied once V8.2 regime labels exist.

## 17. Success Criteria

V8.1 succeeds when:

- No trading behaviour change (Section 13 identity check passes).
- No execution failures.
- No lifecycle corruption.
- Profile labels collected for all active pairs.
- Rollback confirmed.

V8.1 does **not** require profitability improvement. Profit improvement criteria (whipsaw down X%, MFE captured up Y%, PF not below baseline, drawdown not above baseline + Z) apply to later phases, with X, Y, Z set from the Section 15.1 baseline.

## 18. Rollback Plan

```
unset V8_PAIR_PROFILE        # or V8_PAIR_PROFILE=0
```

Result: observer disabled, no new `pair_profile` fields, trading behaviour identical to V7. Records already written keep the field, so all consumers must tolerate both presence and absence.

## 20. Reporting Script: `scripts/report_pair_profile.py`

```python
from __future__ import annotations

import json
import sys
from collections import Counter
from pathlib import Path


def main(path: str = 'reports/lifecycle.jsonl') -> int:
    p = Path(path)
    if not p.exists():
        print(f'No lifecycle file: {p}', file=sys.stderr)
        return 1
    counter: Counter[str] = Counter()
    bad = 0
    with p.open(encoding='utf-8') as handle:
        for line in handle:
            line = line.strip()
            if not line:
                continue
            try:
                row = json.loads(line)
            except json.JSONDecodeError:
                bad += 1
                continue
            prof = row.get('pair_profile')
            if prof is None:
                counter['(absent)'] += 1  # observer not run
            elif isinstance(prof, dict):
                counter[str(prof.get('style', 'unknown'))] += 1
            else:
                counter[str(prof)] += 1  # legacy string form
    print('\nSignals per Profile\n')
    for key, value in sorted(counter.items()):
        print(f'{key:20} {value}')
    if bad:
        print(f'\nSkipped {bad} malformed lines')
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
```

This script only counts. The **outcome join** (lifecycle record to closed trade, giving Signal Count, Win Rate, Profit Factor, Expectancy, Average Hold Time, MFE, MAE per style and per pair) must be specified before a v2 report is built; the join key is open decision D2.

## 21. Roadmap Carry-Forward (renumbered, with review requirements)

| Phase | Name                | Requirements carried from review                                                                                                                                                                                                                                              |
| ----- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| V8.2  | Regime Engine       | TREND / RANGE / VOLATILE / TRANSITION, observe-only. Inputs (ADX, ATR20/120, EMA20/50) are lagging, so add hysteresis or minimum dwell time, define TRANSITION precisely, log previous regime and confidence.                                                                 |
| V8.3  | Structure Score     | `structure_score` = mean of available components (aligned, channel, fractal), 0.0 to 1.0. Regime is a V8.2 field, not a component. Missing components are excluded from the mean (log component count); none available gives null. Confirm components share a 0 to 1 scale. |
| V8.4  | Attribution Engine  | Outcome join, per style / pair / regime reports, CIs.                                                                                                                                                                                                                         |
| V8.5  | Entry Quality Model | Triple-barrier labels rather than separate MFE and MAE targets; ATR-normalized; include spread and slippage; purged/embargoed walk-forward CV.                                                                                                                                |
| V8.6  | TP Quantile Model   | Predict a conservative quantile (for example 30th to 40th percentile of future MFE) or optimize expectancy. A TP at mean MFE is hit only about half the time.                                                                                                                 |
| V8.7  | Adaptive SL         | `SL = max(ATR * 1.5, expected_pullback)` must be paired with size = risk_amount / SL distance, otherwise a wider stop silently raises risk per trade.                                                                                                                       |

V8.2 and V8.3 are independent zero-impact observers and may ship in parallel behind their own flags. V8.5 and later keep the full gate: 24h dry-run, 7d demo, analysis, promotion on statistics.
