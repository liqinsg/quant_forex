## 完成 V8.1 后的唯一下一步

**不要直接进 Entry Model。**

按 Claude 文档路线：**V8.2 Regime Observer**

因为 Pair Profile + Regime 这两个标签到位以后，你才有资格开始 V8.4 Attribution Engine；否则 V8.5 Entry Quality Model 训练时会缺少最有价值的上下文特征。

按照当前项目状态，开发优先级定为：

| 版本 | 内容                | 状态     |
| ---- | ------------------- | -------- |
| V8.1 | Pair Profile        | ✅       |
| V8.2 | Regime Observer     | ← 下一步 |
| V8.3 | Structure Score     |          |
| V8.4 | Attribution Engine  |          |
| V8.5 | Entry Quality Model |          |

这是目前风险最低、信息增益最大的路线。
