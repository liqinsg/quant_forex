## 任务1：每日支撑阻力计算（每日 08:00 执行）

### 输入

- H1 + D1 K线数据：`data/*_H1.csv` / `data/*_D1.csv`
- 覆盖全部交易品种

### 计算内容

1. **支撑/阻力位**
   - 近期 Swing Low/High：left_bars=3, right_bars=3
   - D1/W 关键结构位：前高、前低、周级区间边界
2. **斐波那契分割**
   - 基于最近完整波段（高→低 或 低→高）
   - 关键位：0.236 / 0.382 / 0.5 / 0.618 / 0.786
   - 标注方向（上涨/下跌波段）
3. **与前一日/周对比**
   - 支撑阻力位变动方向与幅度（pips）
   - 斐波那契关键位是否移位
